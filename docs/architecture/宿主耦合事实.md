# 宿主耦合事实（Realm 相关摘录）

> **文档性质**：基于 Survivalcraft 2 宿主 API 的**事实摘录**，供 RealmEX 实现时查阅。  
> **不含**：实施方案或阶段计划。  
> **宿主路径**：`GameDir`（`Survivalcraft.Windows`）或 NuGet `SurvivalcraftAPI.*`。

---

## 1. `Project` 构造与加载

- `Project(GameDatabase, ProjectData)`：从 `ProjectTemplate` 的 `MemberSubsystemTemplate` 列表实例化子系统 → `Initialize` → 按 `Dependencies` 递归 `Load`。
- `LoadSubsystem`：`Dependencies` 为逗号分隔子系统 **Name**；深度超过 100 抛异常。
- `Project` 暴露 `virtual`：`Save`、`Dispose`、`FindSubsystem` 等（`EntitySystem/GameEntitySystem/Project.cs`）——`SandboxProject` 子类的扩展点。

---

## 2. `SubsystemGameInfo`

| 字段 | 用途 |
| --- | --- |
| `WorldDirectoryName` | `TerrainSerializer23` 存档路径 |
| `WorldSeed` | 地形生成与显示 |
| `WorldSettings` | 地貌、季节等 |
| `TotalElapsedGameTime` | 全局经过时间 |

正常新建世界由 `WorldsManager.CreateWorld` 写 `Project.xml`；沙箱 Bootstrap 须满足 `TerrainSerializer` 对目录的契约。

---

## 3. `SubsystemTerrain.Load` 硬依赖（摘录）

`FindSubsystem(..., true)`：

- `SubsystemGameWidgets`、`SubsystemGameInfo`、`SubsystemParticles`、`SubsystemPickables`
- `SubsystemBlockBehaviors`、`SubsystemAnimatedTextures`、`SubsystemFurnitureBlockBehavior`
- `SubsystemPalette`；`BlockGeometryGenerator` 另需 `SubsystemElectricity`、`SubsystemMetersBlockBehavior`
- 可选：`SubsystemSky`、`SubsystemTime`、`SubsystemTimeOfDay`（`throwOnError: false`）

`Load` 内新建 `Terrain`、`TerrainSerializer23(DirectoryName)` 等。

---

## 4. `SubsystemUpdate` 与 `SubsystemTime`

- `SubsystemUpdate.Update`：循环 `SubsystemTime.NextFrame()`，按 `FloatUpdateOrder` tick 所有 `IUpdateable`。
- `SubsystemTime.Load` → `FindSubsystem<SubsystemPlayers>(true)`。

**沙箱并行 tick**：对沙箱 `Project` 调用其 `SubsystemUpdate.Update()`，与主世界并列，不替换宿主主循环。

---

## 5. `SubsystemPlayers`（关键坑）

- `Update`：若 `m_playersData.Count == 0` → `ScreensManager.SwitchScreen("Player", ...)`（`Subsystem/SubsystemPlayers.cs`）。
- 独立沙箱 `Project` 若无玩家数据，**每帧可能跳屏** → RealmEX 使用 `SandboxSubsystemPlayers` 或 dummy `PlayerData`。

---

## 6. `SubsystemDrawing` 与离屏渲染

- `Draw(Camera camera)` 调度已注册 `IDrawable`。
- 离屏模式：`Display.RenderTarget = camera.ViewTexture` 后调用 `Draw`。
- 自添加的 `GameWidget` 须在 `SubsystemGameWidgets` 清理前移除，否则退出存档可能报错。

---

## 7. `GameManager` 单例

- 运行时仅一个 `GameManager.m_project` 表示**当前主世界**。
- RealmEX **不得**将沙箱 `Project` 赋给 `GameManager`；沙箱由 `RealmHost` 自管生命周期。

---

## 8. `TerrainChunkState`

```
NotLoaded=0 … InvalidContents4=4 … Valid=9
```

设备 `Component` 常检查 chunk `State` 为 `Valid` 才执行逻辑；`RealmBootstrap` 铺景后须使相关 chunk 达到可仿真状态。

---

## 9. Mod Hook 惯例

- 许多 Hook 默认使用 `GameManager.Project`。
- 沙箱路径须**显式传递**沙箱 `Project`；RealmEX 文档约定下游 Hook 实现者检查 `project` 参数。
